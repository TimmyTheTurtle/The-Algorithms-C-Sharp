# LLM Augmentation Algorithm Curriculum

**Goal:** Master deterministic algorithms for augmenting LLM systems with structured logic, constraint satisfaction, and precise computation.

**Context:** You're building agentic AI systems where LLMs handle reasoning/generation, but deterministic algorithms provide guardrails, validation, optimization, and structured problem-solving.

**Time Investment:** 3-5 hours/week | **Total Duration:** 10-12 weeks

---

## How to Use This Curriculum

### Weekly Workflow (3-5 hours)
1. **Monday:** Read algorithm explanation, understand the "why"
2. **Tuesday-Wednesday:** Implement in Jupyter notebook, play with parameters
3. **Thursday:** Apply to a small LLM augmentation scenario
4. **Friday:** Reflect, consolidate, prep for next week

### Jupyter Notebooks Structure
- Create one `.ipynb` per algorithm (or group related ones)
- Include: theory, implementation, examples, performance comparison
- Add challenge problems: "How would you use this to validate LLM output?"

### Red Flags (Things to Study Harder)
- If you can't explain why an algorithm matters for LLMs, you don't understand it yet
- If you can't write it from scratch, keep practicing
- If you can't modify it for your use case, you're just memorizing

## Why This Order?

1. **Strings first** → Direct application to LLM I/O
2. **Search second** → Foundation for all other algorithms
3. **Graphs third** → Core of LLM reasoning augmentation
4. **Pathfinding fourth** → Combines graphs + optimization
5. **DP and advanced last** → Build on everything else

This sequence mirrors how you'd build a production LLM system:
- Parse/validate inputs (strings)
- Query structured data (search)
- Model relationships (graphs)
- Find optimal solutions (pathfinding)
- Optimize under constraints (DP + advanced)

## Algorithms We're Skipping (And Why)

- ❌ **Cryptography** - Not needed for LLM augmentation
- ❌ **Advanced ML algorithms** - That's LLM's job
- ❌ **Pure mathematical algorithms** - Use libraries instead
- ❌ **Obscure sorting variants** - You learned the key ones
- ❌ **Highly theoretical algorithms** - Practical > theoretical right now
